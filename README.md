# 小铭邮件百宝箱 (Company Mail Toolkit)

多功能邮件转换与管理工具，支持 EML、PST、OST、IMAP、Office 365 等多种邮件格式和平台。

## 主要功能

### 1. 转换为 PST

将各种邮件格式转换为 PST 文件，方便导入 Outlook。

| 功能 | 说明 |
|------|------|
| **EML 转 PST** | 将 EML 邮件文件批量转换为 PST 格式 |
| **OST 转 PST** | 将 Outlook OST 数据文件转换为 PST |
| **IMAP 收件转 PST** | 从 IMAP 服务器收取邮件并导出为 PST |
| **IMAP 多线程转 PST** | 多线程并发从 IMAP 服务器同步邮件 |

### 2. 邮件提取

从 PST/OST 文件中提取邮件内容。

| 功能 | 说明 |
|------|------|
| **IMAP 邮件提取 EML(MSG)** | 从 IMAP 服务器下载邮件保存为 EML 或 MSG 格式 |
| **提取邮件** | 从 PST/OST 文件提取邮件，支持多种导出格式 |

### 3. 单用户同步 (O365)

将本地邮件数据同步到 Office 365。

| 功能 | 说明 |
|------|------|
| **EML 导入** | 将 EML 文件夹导入到 Office 365 邮箱 |
| **同步联系人/日历** | 将联系人（CSV/VCF）和日历（ICS）同步到 O365 |

### 4. 用户批量同步到 O365

批量将多个用户的数据同步到 Office 365。

| 功能 | 说明 |
|------|------|
| **登录** | 配置 O365 批量同步账户 |
| **PST 同步邮件** | 批量将 PST 文件导入到 O365 用户邮箱 |
| **PST 同步联系人** | 批量将联系人从 PST 导入到 O365 |
| **PST 同步日历** | 批量将日历从 PST 导入到 O365 |
| **CSV 同步联系人** | 批量将 CSV 联系人文件导入到 O365 |
| **VCF 文件夹联系人同步** | 批量将 VCF 文件夹中的联系人导入到 O365 |
| **文件夹日历同步** | 批量将日历文件导入到 O365 |

### 5. Exchange Online 百宝箱

Exchange Online 管理工具集。

| 功能 | 说明 |
|------|------|
| **登录** | 使用 OAuth2 或客户端密码登录 Exchange Online |
| **账户管理** | 管理 O365 用户账户 |
| **组管理** | 管理 Exchange 分布组和安全组 |
| **移动设备管理** | 管理 Exchange ActiveSync 移动设备 |
| **邮件流量搜索** | 搜索邮件流量日志 |
| **邮件迁移** | 将邮箱从本地 Exchange 迁移到 O365 |
| **邮件搜索导出** | 使用 Graph API 搜索所有用户邮件并导出到 PST |
| **邮件搜索导出删除** | 搜索邮件、导出 PST 后删除源邮件 |
| **WHOIS 查询** | 查询域名 WHOIS 信息 |
| **DNS 查询** | 查询域名的 DNS 记录 |

### 6. Exchange On-Premise 百宝箱

本地 Exchange Server 管理工具。

| 功能 | 说明 |
|------|------|
| 提供 Exchange 本地服务器的管理功能 |

## 系统要求

- Windows 10/11 或 Windows Server
- .NET Framework 4.8
- Microsoft Outlook（用于 PST 文件操作）
- Python 3.x（部分功能需要）

## 安装

1. 下载最新版本的 ZIP 包
2. 解压到本地目录
3. 运行 `MailConverter.exe`
