# 单用户同步（O365）界面重构设计方案

## 1. 背景

当前 `CreateOffice365Panel()` 存在以下问题：
- 元素没有清晰分组，认证区、源文件区、目标文件夹区混在一起
- 分隔线过多（4条），视觉噪音大
- PST 导入选项和 EML 导入流程混在一个界面
- 进度条和状态显示位置不够突出

## 2. 设计目标

按照工程级别标准重新设计界面，采用分组卡片式布局，清晰分离不同功能区域。

## 3. 视觉规范

### 3.1 卡片样式

- **背景色**: `Color.White`
- **边框**: `Color.FromArgb(220, 220, 220)` 浅灰，1px
- **阴影效果**: 通过 Panel 的 `Paint` 事件绘制双层边框模拟阴影
- **圆角**: 4px（通过 `CreateRegion` 裁剪实现）
- **内边距**: 15px
- **卡片间距**: 12px

### 3.2 标题样式

- **字体**: `Microsoft Sans Serif, 9F, FontStyle.Bold`
- **颜色**: `Color.FromArgb(50, 50, 50)` 深灰
- **图标**: 使用 emoji 或 Bootstrap Icon 字符

### 3.3 输入控件样式

- **下拉框/文本框高度**: 26px
- **边框颜色**: `Color.FromArgb(180, 180, 180)`
- **圆角**: 3px
- **聚焦边框**: `Color.FromArgb(0, 120, 215)`

### 3.4 按钮样式

**主按钮**（开始导入）:
- 背景: `Color.FromArgb(0, 120, 215)`
- 文字: 白色
- 圆角: 4px
- 高度: 36px

**次按钮**（浏览、取消）:
- 背景: `Color.FromArgb(245, 245, 245)`
- 文字: `Color.FromArgb(50, 50, 50)`
- 边框: `Color.FromArgb(200, 200, 200)`
- 圆角: 4px
- 高度: 26px

### 3.5 进度条样式

- **高度**: 6px
- **圆角**: 3px
- **背景色**: `Color.FromArgb(230, 230, 230)`
- **填充色**: `Color.FromArgb(0, 120, 215)`

## 4. Tab 结构

```
单用户同步（O365）
```

## 7. 实现方式

### 7.1 辅助方法

```csharp
// 创建卡片面板（带阴影效果）
private Panel CreateCardPanel(string title)

// 统一样式辅助
private void StyleTextBox(TextBox txt)
private void StyleComboBox(ComboBox cmb)
private void StylePrimaryButton(Button btn)
private void StyleSecondaryButton(Button btn)
```

### 7.2 卡片阴影实现

通过 Panel 的 `Paint` 事件绘制双层边框：
```csharp
private Panel CreateCardPanel(string title)
{
    var card = new Panel { BackColor = Color.White, Height = height };
    card.Paint += (s, e) => {
        // 外层阴影边框
        e.Graphics.DrawRectangle(new Pen(Color.FromArgb(180, 180, 180)), 0, 0, card.Width - 1, card.Height - 1);
        // 内层白色边框
        e.Graphics.DrawRectangle(new Pen(Color.White), 0, 0, card.Width - 2, card.Height - 2);
    };
    return card;
}
```

### 7.4 样式统一

联系人/日历同步的现有方法保持不变，仅添加样式辅助方法调用进行视觉统一。

**不支持** - 保持当前浅色主题，与整体应用风格一致，后续如需支持可扩展。

## 10. 注意事项

1. 保持现有功能逻辑不变，只重构 UI 布局
2. 字段引用（`cmbO365SavedAccounts`、`txtO365ClientId` 等）保持不变
3. 事件处理逻辑（`BtnO365Import_Click` 等）保持不变
4. 进度回调机制保持不变
