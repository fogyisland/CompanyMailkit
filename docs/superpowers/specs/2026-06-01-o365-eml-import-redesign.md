# 单用户同步(O365) EML导入界面重构设计方案

## 1. 概述

重新设计"单用户同步(O365)"中EML导入页面，采用纯平面布局，通过分隔线区分区块，自适应窗口拉伸。

## 2. 设计维度

| 维度 | 选择 |
|------|------|
| 填充策略 | Dock+Anchor 自适应拉伸 |
| 卡片风格 | 纯平面 + 分隔线（无阴影边框） |
| 区块排列 | 垂直堆叠（账户配置 → 源文件配置 → 操作区） |
| 表单对齐 | 标签60px宽，输入框从70px开始 |

## 3. 区块结构

### 区块1: 账户配置

```
个人账户: [下拉框---------------------------------------]
Client ID:  [输入框--------]  租户ID: [输入框---] [使用 Microsoft 登录]
```

### 区块2: 源文件配置

```
邮件来源: [下拉框]  目标文件夹: [下拉框]
源路径:   [输入框-----------------------] [浏览...]
```

### 区块3: 操作区

```
[▶ 开始导入]

已处理: 45/100  ████████████████░░░░░░░░░░ 45%
```

## 4. 控件规格

| 控件 | 规格 |
|------|------|
| 主面板 | Dock=Fill, 无背景色 |
| 分隔线 | Height=1, Color=LightGray, Anchor=Left|Right |
| 标签 | Width=60(左对齐), Font=Microsoft Sans Serif 9pt |
| 输入框 | Height=26, 从70px开始 |
| 主按钮 | 高度36, 蓝色(#0078D4), 白色文字 |
| 次按钮 | 高度26, 灰色背景, 扁平样式 |
| 进度条 | 高度12, 连续样式, 百分比显示在左侧 |

## 5. Anchor 策略

- 主面板: Dock=Fill
- 各区块: Anchor=Left|Right|Top，Top从20开始
- 输入框: Anchor=Left|Right（宽度自适应）
- 按钮: Anchor=None（固定位置）
